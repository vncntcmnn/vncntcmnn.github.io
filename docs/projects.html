rodet (rotated)

2025

Open sourced at Safran.AI.

Pure PyTorch implementation of rotated object detection models with oriented bounding boxes—no CUDA kernels required. Features rotated bounding boxes with 5-parameter format [cx, cy, w, h, angle], pretrained CSPResNet backbones, and pluggable oriented IoU implementations. Clean implementation of the effective PPYOLOE-R rotated object detection model from PaddleDetection.
